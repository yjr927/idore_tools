# 后续接入真实 API

当前工程默认禁止外部生成。配置页面中的 URL 与模型 ID 都是占位值，只写入本机，不构成真实连接。请勿把 API key 粘贴进网页、JSON 配置、聊天、代码或 Git 仓库。

## 1. 趋势数据源

实现 `adapters.py` 中的 `TrendProvider.discover(region, category)`，返回与 `/api/state` 中 trends 一致的结构。真实接入时新增并保存来源 URL、观察时间、数据覆盖范围与两次指标快照。不能把样本候选称为全站实时排名。

参考视频仅用于抽象拆解。未授权参考片不进入成片，也不传给生成供应商。第三方趋势接口的使用权限、商业条款与时效需要单独验证。

## 2. 自有素材库

`AssetProvider.list_owned()` 是素材源接口预留。现版本的本地素材由 Store 直接管理，不通过这个占位协议调用外部库。若后续接飞书、Drive、NAS 或对象存储，应仅访问指定素材范围，保留权属与审核状态。共享网页链接不是模型可读取的媒体直链。

可增加 ffprobe 提取时长、编码、画幅与音轨，并在确认素材传输范围后引入可审核的视觉标签。注意代码的 `aspect_ratio` 当前只是人工填写值。

## 3. Seedance 2.5

实现 `GenerationProvider.submit(plan)` 和 `status(remote_id)`，之后再加入结果下载、重试、持久队列、费用与时长校验。当前 `DisabledGenerationProvider` 始终抛出“未接入”错误，防止把模拟误当成实际生成。

在服务端环境变量或正式密钥管理中读取凭据。选择火山方舟或 BytePlus 后，按该账户最新官方文档核对模型 ID、输入格式、时长/画幅限制、真人限制、保存规则、价格与异步状态。不要混用不同供应商的账号和模型 ID。

预留的 API Base URL 字段不会自动被 submit 调用。工程中没有任何伪装成真实调用的“万能端点”。接入前需把实际请求与响应适配器写好并单独测试。

真实调用前至少落实：

- 哪些自有素材可以传到哪个供应商。
- 单条和每日预算，包括失败重试与不满意结果成本。
- 每条补镜的实际模型最小时长与裁剪规则。分镜缺口秒数不等于计费秒数。
- 幂等提交、超时恢复、任务查询、结果文件验证。
- 自有素材比例、模型输入许可、人工审核硬性条件。

## 4. 合成、审核与发布

现在的预演是浏览器逐段播放，不产生合成文件。以后应独立实现 Renderer：使用有权使用的素材与生成片段进行转场、字幕和音轨合成，输出真实文件与来源清单，并检测实际时长和编码。

本地“批准计划”仅改变审核状态。不能把这个动作暗中接到发布。生产版应区分计划批准、允许花费/传输、成片审核和明确发布权限。此版本没有发布接口。

## 5. 不变的本地 HTTP 接口

网页仅通过同源 `/api/*` 与 Python 服务通信。实际请求/响应详见 `API.md`，建议保持前端契约稳定，把供应商差异封装在服务端。API 需增加真实执行阶段与错误类型后再开放生产模式，不能只把 `is_simulation` 设为 false。
