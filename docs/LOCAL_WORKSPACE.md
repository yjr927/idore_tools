# idore · TikTok 短视频平台

可实际操作的 localhost 网页：示例趋势 → 本机自有素材 → 分镜匹配 → 模拟任务 → 人工审核。

**当前没有接通 TikTok 或 Seedance，没有真实视频生成，也不会自动发布。** 页面、上传、任务存储、标签匹配、审核和 JSON 导出是真实可用的；趋势数据与生成进度明确标记为模拟。无需 API key，不产生生成费用。

## 免费真实视频发现

打开「寻找真实视频」或 `http://localhost:8765/#discover`，选择手势／舞蹈、变装、POV，点击「寻找真实视频」。无需账号、API Key 或付费服务。

程序读取 SocialPilot 和 Later 的公开趋势精选，提取完整 TikTok 原视频链接。按文章标题和描述筛选玩法，按视频 ID 去重，并保存来源、首次发现与最近采集时间、收藏和任务结果。它不是 TikTok 全站搜索或实时热榜；不能保证来源持续可用、视频仍可播放、单人动作符合要求或多个作者拍的是同一玩法。未知的热度、发布时间和视觉判断均不填造。

原视频使用 TikTok 官方播放器，可能遇到登录、地域、删除或服务端错误；可改用原链接查看。支持手动加入完整视频链接，通过 TikTok 官方 oEmbed 读取预览信息。不会下载原视频，也没有接入付费采集、AI 视频分析或每日调度。

失败不会清空已有结果。每次采集间隔至少 30 秒；关闭服务后停止采集。采集与收藏保存在 `data/state.json`。网络请求只用于这两个固定公开来源和手动原链接的官方预览；角色素材不上传。

## 30 秒开始

需要 **Python 3.10 或更高版本**，无其他依赖，不需要 Node.js、npm 或 pip 安装。

1. 解压整个 `motion-lab-local.zip`，进入 `tiktok_agent_web` 文件夹。
2. macOS：双击 `start.command`。Windows：双击 `start.bat`。
3. 浏览器会打开 **http://localhost:8765**（自动打开的 127.0.0.1 地址等效）。保持启动窗口打开。

如果脚本未能双击运行，打开终端，进入解压后的文件夹：

```sh
python3 server.py --open
```

Windows 也可运行：

```powershell
py -3 server.py --open
```

如果端口被占用：

```sh
python3 server.py --open --port 8766
```

随后访问 http://localhost:8766 。停止服务：在启动终端按 Ctrl+C。重新启动后，之前的素材、设置和任务都还在。

Python 未安装时，请从 https://www.python.org/downloads/ 安装 Python 3.10+。不要双击 static/index.html，这个应用需要本地 Python 服务。

## 第一次建议这样体验

1. 在「趋势发现」选择「晨间仪式感」，点击「拆解并创作」。
2. 开启「包含示例素材」可直接试用完整流程。示例素材只有元数据与插画，并不是真实视频。
3. 点击「创建模拟任务」，约 4 秒后任务进入审核队列。
4. 「预演并审核」可逐段查看计划；批准、要求修改或退回都只更改本地状态。
5. 下载 JSON 任务单，查看来源、分镜、提示词及保护条件。这个 JSON 不是视频文件。
6. 导入自己的图片或视频，添加与趋势一致的标签，如 `morning, coffee, routine`；关闭示例素材开关后重新匹配，即可只使用真实导入文件。

## idore 角色素材

内置 44 张用户提供的角色图片、15 个万圣节角色分镜模板。素材库支持按角色和阶段筛选；分镜以独立镜头标签匹配同一角色的素材。图片以 9:16 目标画布完整预演，不自动裁剪或生成视频。`library/` 保存可迁移素材，首次启动复制到本机素材库；不会修改原始图片。

## 已实现

- 中文桌面/移动端响应式工作台，六个带插画的示例趋势。
- 关键词、市场、内容分类筛选。
- 本地图片/视频上传，批量选择与拖放，素材标签与可用状态编辑。
- 基于标签、画幅、使用权、审核状态与时长的确定性素材匹配。
- 自有素材占比检查、补镜缺口提示、可编辑创作指令与任务名称。
- 可手动选择素材、关闭示例素材、查看镜头来源。
- 约 4 秒的模拟队列，取消、重试、审核状态与备注。
- 本地图片/视频逐段预演；缺失媒体显示明确的示意占位。
- JSON 任务单与配置导出。
- 配置、任务与实际文件持久保存在本机。
- 可替换的 Python 接口契约与 HTTP API，详见 `docs/API.md` 与 `adapters.py`。

## 文件与数据

- `server.py`：本地 API 与服务端逻辑。
- `static/`：无需编译的 HTML / CSS / JavaScript 网页。
- `adapters.py`：后续真实接口的边界。
- `docs/API.md`：请求/响应、状态机、安全限制和接入注意事项。
- `docs/INTEGRATION.md`：中文接入路线。
- `tests/`：后端集成测试。
- `data/state.json`：首次运行后创建，保存设置、任务与素材记录。
- `data/media/`：首次上传后保存原始媒体文件。

不要删除 `data/`，否则会失去素材和计划。备份时复制整个 `data/` 文件夹。安装包不包含测试运行时数据或任何私人文件。

## 支持与限制

图片：PNG、JPG、WebP、GIF。视频：MP4、WebM、MOV。网页限制每个原始文件 32 MB；服务端总 JSON 请求体限制 50 MiB。推荐 H.264 编码的 MP4，部分 MOV 编码浏览器无法播放。

上传视频时，浏览器尝试读取时长；失败时采用填写的默认秒数。后端校验类型与文件头，不做完整解码。画幅为手动匹配标签，不会自动裁剪。标签是精确匹配，没有视觉识别或中英文语义翻译。真人肖像、音乐及供应商限制须在未来真实接入时另外审查。

当前没有实时热榜、自动视觉分析、真实模型调用、真实成片合成、价格计算、发布或每天自动执行。修改接口地址只保存占位信息，不会激活网络请求。默认每日最多创建 3 个模拟任务，按 UTC 日期计数，可在设置调整。

服务只监听本机 127.0.0.1。它不是有登录权限控制的多人生产系统，请不要将它暴露到公网或通过公开隧道分享。

## 测试

```sh
python3 -m unittest discover -s tests -v
```

开发预览可选使用 `python3 dev.py --port 4173`，它将测试数据隔离到 `.preview-data/`；日常使用请运行 `server.py`。`package.json` 仅供开发预览工具调用，用户运行不需要 Node.js。
