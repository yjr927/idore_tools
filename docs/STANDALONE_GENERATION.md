# 独立网站：用角色图跟拍 TikTok 动作

入口：[打开独立创作页](https://yjr927.github.io/idore_tools/create.html)。这是无需启动本机服务的视频跟拍页面。功能是否已经上线，以该地址实际显示的版本为准。

## 本次 KAI＋Bizzyboom 的实际结果

直接提交 Bizzyboom 真人原片的测试曾成功解析并传给生成服务，但该直接输入方式**没有生成成片**。供应商明确返回 `InputVideoSensitiveContentDetected.PrivacyInformation`，指出输入视频可能包含真人。页面会阻止这条已知参考再次提交付费生成；生成入口可使用不代表这条配对已经可生成。

这是模型服务商对参考素材的限制，改提示词、重新下载或重复提交不能解决，因此不再重试直接输入该真人视频。下述成功版本使用另行生成并审核的白模动作参考。参见 [BytePlus 的人物参考素材说明](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/seedance-portrait-asset-guide)。

## 已完成的白模方式

2026-11-15，GitHub 云端从同一条 6 秒原片提取身体与双手动作，渲染不含原片像素的新白模，再将 **KAI 图片＋白模视频**交给 Seedance 2.5，已成功生成第一版 KAI 成片。实际输出为 720×1280、约 6 秒、24fps、无音轨；OpenRouter 回执费用为 $1.66464。[查看生成记录](https://github.com/yjr927/idore_tools/actions/runs/43790641550)。

网页新增“使用已准备的白模动作”：预览这条已审核参考，自动选定 Seedance 2.5／6 秒／720p／9:16，再由用户明确确认生成。页面会核对固定版本和完整文件校验值；按钮本身不提交付费生成。原真人视频的已知拒绝仍保持阻止。

此白模预设只对应本次指定动作，**尚不等于任意 TikTok 链接都能在网页自动转白模**。当前提取和渲染在 GitHub 工作流中完成；手部遮挡和推断关节仍会影响精确度，不承诺逐指完全一致。白模审核也不等于供应商对所有后续素材的预先授权。

## 连接与准备

1. 点击“连接 OpenRouter”，在 OpenRouter 官方页面完成授权，再返回创作页。授权取得的 API key 只保留在当前页面内存；刷新、关闭或重新打开页面后需要重新连接。授权过程中临时保存的一次性校验信息不包含 API key。
2. 选择已获准使用的角色图。当前入口以 **KAI／男生／单人** 为目标；这不表示其他素材已完成分类或被公开。角色图片控制身份、外观与服饰，不使用照片的静止姿势代替动作。
3. 可点击“使用已准备的白模动作”预览本次动作；使用其他参考时，粘贴公开的完整 TikTok 视频链接，例如 `https://www.tiktok.com/@作者/video/数字ID`，点击“读取原片（不扣费）”。短链接、需要登录才能观看的视频和无法解析的原片不能用于这条流程。
4. 分别确认角色和原片的素材分组及人数。只接受同为男生、单人的配对；女生、多人或尚未确认的输入不能直接提交。待确认信息需要人工确认，页面不会仅凭姓名或脸部猜测性别。

页面通过 **TikWM 第三方解析服务**取得公开原片信息。TikWM 不是 TikTok 官方 API；只把公开完整链接交给它，不把 OpenRouter key 或角色图片交给它。页面不登录 TikTok、不导入账号 Cookie，也不绕过登录、验证码或其他访问限制。解析失败、来源编号／作者不匹配或无法取得受支持的视频文件时停止，不用文字编舞或示例视频替代。

## 选择模型并生成

选择账号当前可用的 Seedance 2 或更新版本，以及该模型支持的时长、分辨率和画幅。不会自动换成另一款付费模型。检查提示词、两项素材与费用确认后，点击“生成 KAI 跟拍视频（消耗 OpenRouter 余额）”。

提交前页面会重新解析原片并读取当前模型能力。实际请求同时传入两项参考：

- **角色图片**：锁定 KAI 的身份、服饰和配饰。
- **动作参考视频**：原片或已审核白模提供可见的手势、动作顺序、节奏、姿态和镜头。

该流程使用图片与视频参考，不同时添加首尾帧；无音频生成。提示词要求单人、自然手指、身份与服饰稳定，不添加人物或变装，不编造原片没有的逐秒动作。模型仍可能出现动作或角色细节偏差，需要查看成片后判断效果。

读取原片、连接和浏览模型不会提交视频生成。只有明确点击生成并确认素材传输与额度使用后，才会请求 OpenRouter 及所选模型服务商。网站不会自动发布到 TikTok。

原片能够解析，不代表模型服务商已经接受素材或成片已经生成。素材类型、模型权限或供应商要求仍可能导致拒绝；查看本次任务结果后再处理，不能把“原片读取成功”当成“视频生成成功”。

## 记录、查询和提交结果不确定

本浏览器可保存请求标识、内容指纹、远端任务编号、参数和状态等安全记录；这些记录不会保存 API key、角色图片数据或临时原片地址。记录属于当前浏览器，不会自动同步到其他设备。远端进度查询至少间隔 30 秒；继续查询已有任务不等于再生成一条。

若提交超时、网络断开或返回结果无法确认，页面会阻止相同请求直接重发。先检查已有记录和 OpenRouter 任务／用量，确认是否已经接单；不要通过刷新页面、重复点击或新建同样的任务来绕过此状态。再次明确生成另一条是新的付费操作。

## 与现有 Work、GitHub 和 OpenAI 功能的关系

Work 云端每日采集仍独立运行：采集、分类与趋势看板不因打开生成页而改变，也不会自动扣视频额度。趋势看板的刷新按钮只读取已发布采集数据。

GitHub Secrets 中的 OpenRouter／OpenAI 密钥仍只供对应云端任务使用，不会下发到独立网站，也不能被页面读回。独立页面使用本次 OpenRouter 官方授权，与 GitHub 云端密钥分别管理。

**当前独立页提供视频动作跟拍的提交入口。** OpenAI 前后造型图、英文文案与 hashtags 仍使用已有本机 `/generate` 或相应 GitHub 手动创作任务；它们尚未因此迁入新页面。参考：[原有创作入口与操作说明](INTEGRATION.md)。
