# 验证记录

验证针对交付的本地模拟版本，不代表真实 TikTok 或 Seedance API 已测试。

## 自动化检查

- Python 标准库后端：15 项 HTTP 集成测试通过。
- JavaScript：`node --check static/app.js` 语法检查通过。
- Python：`py_compile` 通过。
- 使用临时数据目录，不把测试状态打包给用户。

后端测试覆盖：初始示例与持久化、权属/审核/画幅筛选、标签匹配、无重复源片区间、关闭示例素材、手动空选素材、上传与删除限制、任务状态流、审核/重试、幂等、每日上限、导出模拟声明、Host/Origin 检查、无效 JSON/NaN/参数/数据大小、媒体 Range 请求（GET/HEAD、206/416、前缀/后缀/开放区间）。

## 浏览器检查

在本地 Chromium 中验证：

- 页面与静态资源正常加载，趋势发现和所有导航正常，搜索无结果与清空筛选正常。
- 开关示例素材可正确改变匹配结果。
- 真实 PNG 与 H.264 MP4 测试文件上传、本地展示、名称/标签编辑、关闭示例后的真实素材匹配。MP4 浏览器解码成功，读取 12 秒时长与 180×320 分辨率。
- 模拟任务创建、进入审核、分镜预演、批准及要求修改。
- 取消模拟并重试。
- MP4 的 Range 修复后复测通过：第二分镜（4–8 秒）实际播放位置 4.3645 秒，seekableEnd 为 12 秒，视频处于播放状态且无解码错误。
- 设置保存，重复导航后状态仍存在。
- 创作面板可打开与关闭，不破坏导航。
- 桌面视觉检查；通过浏览器缩放测试 674px 与 393px 的 CSS 窄视口，未发现水平溢出；393px 分镜弹窗未溢出。

为防止保存过程中关闭/重开弹窗导致旧回调污染新面板，上传和任务保存期间暂时阻止关闭。较旧的素材匹配响应不能覆盖最新请求。
